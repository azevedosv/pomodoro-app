Pomodoro App

Timer de foco com tarefas, histórico, tema claro e escuro e uma trilha sonora sugerida pelo seu humor.

Feito com React Native, Expo Router, AsyncStorage e as APIs Jamendo e Freesound.

Desenvolvimento Mobile, Prof. Vitor Vidigal. Dupla: Gabriel de Azevedo Silva e Paulo Victor Rodrigues Moraes.

Navegue com as setas do teclado ou com os botões abaixo.

Visão geral e estrutura do projeto

  • Cinco telas: Timer, Tarefas, Histórico e Configurações (abas) e Humor (pilha).
  • Pastas por responsabilidade: rotas em app, peças visuais em components, dados compartilhados em context, lógica de busca em hooks e utils.
  • Dados guardados no aparelho: o app funciona sem internet, exceto a busca de música e sons.
  • Cada arquivo em app vira uma rota. Os parênteses em (tabs) agrupam as abas sem entrar no endereço.

Persistência local e estado global

src/utils/storage.jssrc/context/AppContext.js
  • O AsyncStorage guarda só texto, então JSON.stringify converte na ida e JSON.parse na volta.
  • Cinco chaves: @pomodoro_config, _ciclo, _tarefas, _historico e _audio.
  • O AppProvider lê a configuração ao abrir o app (useEffect com lista vazia) e só desenha as telas depois, para o tema não piscar.
  • Qualquer tela usa useApp() para pegar config, tema e salvarConfig.
  • Salvar atualiza a tela na hora e grava no aparelho.
// storage.js
export async function salvarDados(chave, valor) {
  await AsyncStorage.setItem(chave, JSON.stringify(valor));
}
export async function lerDados(chave, padrao) {
  const texto = await AsyncStorage.getItem(chave);
  return texto !== null ? JSON.parse(texto) : padrao;
}

// AppContext.js
useEffect(() => {
  async function carregar() {
    const salva = await lerDados(CHAVES.config, null);
    if (salva) setConfig({ ...CONFIG_PADRAO, ...salva });
    setCarregado(true);
  }
  carregar();
}, []);
const tema = config.temaEscuro ? TEMA_ESCURO : TEMA_CLARO;

Tarefas: cadastrar, selecionar, concluir e excluir

src/app/(tabs)/tarefas.js
  • Cada tarefa é um objeto: id, titulo, concluida, pomodoros e selecionada.
  • Texto vazio é bloqueado, com mensagem de erro.
  • Só uma tarefa pode ser a ativa. Tocar de novo desmarca, e tarefa concluída não pode ser selecionada.
  • Concluir risca o título. A lixeira exclui.
  • A lista usa FlatList e tem texto de lista vazia.
  • useFocusEffect relê as tarefas toda vez que a aba aparece, porque o Timer soma pomodoros nelas.
  • No Timer, um Modal permite trocar a tarefa ativa sem sair da tela.
async function atualizarTarefas(novaLista) {
  setTarefas(novaLista);                    // tela
  await salvarDados(CHAVES.tarefas, novaLista); // aparelho
}

function selecionar(id) {
  atualizarTarefas(
    tarefas.map((t) => ({
      ...t,
      selecionada: t.id === id ? !t.selecionada : false,
    }))
  );
}

Timer: a contagem regressiva

src/app/(tabs)/index.jssrc/utils/tempo.js
  • Relógio de 24 horas em tempo real: setInterval dentro de um useEffect, com a função de limpeza que para o intervalo ao sair da tela.
  • A contagem não subtrai um por segundo. Ela guarda o horário de término e calcula o que falta, então continua certa se a tela bloquear.
  • O horário de término fica em um useRef, que guarda valor sem redesenhar a tela.
  • restante começa em null, que quer dizer ainda não começou. Assim o contador acompanha mudanças nas Configurações.
  • O botão principal alterna entre Iniciar, Pausar e Continuar, e o Resetar reinicia o modo atual.
  • formatarContador transforma segundos em MM:SS.
function iniciar() {
  fimRef.current = Date.now() + segundosExibidos * 1000;
  setRodando(true);
}

useEffect(() => {
  if (!rodando) return;
  const intervalo = setInterval(() => {
    const faltam = Math.max(0,
      Math.ceil((fimRef.current - Date.now()) / 1000));
    setRestante(faltam);
    if (faltam === 0) setRodando(false);
  }, 250);
  return () => clearInterval(intervalo);
}, [rodando]);

Timer: ciclos, pausas e finalização antecipada

src/app/(tabs)/index.js
  • Três modos: foco, pausa curta e pausa longa. A função finalizarModo decide o próximo.
  • Ao fim de cada foco o ciclo sobe um. Se há meta e ela foi atingida, o ciclo zera e a pausa é longa. Sem meta, o ciclo só conta para cima.
  • Pausa longa a cada X focos, usando o resto da divisão (%).
  • O botão Finalizar encerra o foco na hora. A sessão grava os minutos que realmente passaram, com mínimo de um.
  • O botão Pular pausa volta direto ao foco e não gera sessão.
  • Um useRef funciona como trava e impede registrar a mesma sessão duas vezes num toque duplo. O bloco finally sempre a libera.
  • Ao fim do tempo, o celular vibra.
const novoCiclo = ciclo + 1;
const metaAtingida =
  config.meta !== null && novoCiclo >= config.meta;

let proximo = "pausaCurta";
if (metaAtingida ||
    novoCiclo % config.pausaLongaACada === 0) {
  proximo = "pausaLonga";
}

// finalização antecipada
const decorridos = segundosTotais - segundosExibidos;
const minutos = Math.max(1, Math.round(decorridos / 60));
finalizarModo({ minutos, manual: true });

Sessões e Histórico

src/app/(tabs)/index.jssrc/app/(tabs)/historico.jssrc/components/CardSessao.jssrc/utils/tempo.js
  • Cada foco concluído soma um pomodoro na tarefa ativa e grava uma sessão no início da lista, então a mais recente aparece primeiro.
  • A sessão guarda tarefa, duração, data e hora, e o humor, quando a pessoa escolhe um.
  • O padrão é sempre ler, criar uma lista nova e gravar de volta, sem alterar a lista original.
  • O Histórico calcula os totais a partir da lista, sem estado extra: length para as sessões e reduce para os minutos.
  • O cartão CardSessao mostra tarefa, duração, data e o emoji do humor.
  • Limpar histórico pede confirmação com Alert.
  • O Timer mostra Pomodoros hoje, calculado com ehHoje, que compara dia, mês e ano.

Consumo de API com carregamento e erro

src/utils/api.jssrc/hooks/useBusca.jssrc/components/SecaoBusca.js.env
  • Duas APIs externas: Jamendo (músicas) e Freesound (sons), com fetch.
  • As respostas são convertidas para o mesmo formato (id, titulo, autor, url), e o mesmo cartão serve para as duas.
  • O hook useBusca controla lista, item escolhido, loading e erro, e é usado uma vez para cada API.
  • Os erros viram mensagens em português: sem internet, erro do servidor, chave ausente ou nenhum resultado.
  • Cada seção tem o seu Tentar de novo. Se uma falha, a outra continua funcionando.
  • Uma bandeira ativo ignora respostas antigas quando o humor muda no meio de uma busca.
  • As chaves ficam no .env, fora do GitHub, e o .env.example mostra o que preencher.
// useBusca.js
setCarregando(true);
setErro("");
try {
  const lista = await buscar(termoAleatorio(termos));
  setItens(lista);
  setEscolhido(lista[0].id);
} catch (e) {
  setErro(e.message);
} finally {
  setCarregando(false);
}

// api.js
resposta = await fetch(url);
if (!resposta.ok) {
  throw new Error(`O servidor respondeu com erro (${resposta.status}).`);
}

Humor e áudio: o cruzamento dos dados

src/app/humor.jssrc/utils/humor.jssrc/app/(tabs)/index.js
  • O humor vem da própria pessoa: cansado, estressado, neutro ou animado.
  • Um mapa traduz humor em termos de busca, e um termo é sorteado a cada vez. Exemplo: cansado vira ambient na Jamendo e rain na Freesound.
  • A tela Humor abre sozinha quando um foco termina, levando o id da sessão como parâmetro de rota. O humor escolhido é gravado nessa sessão.
  • A música e o som escolhidos ficam guardados no aparelho.
  • Ao tocar em Iniciar, o Timer toca a música no foco e o som na pausa, em repetição.
  • Pausar pausa o áudio, e resetar, finalizar ou terminar o tempo o param.
  • O áudio nunca impede o Timer: toda chamada passa por uma função que captura erros.
  • O crédito do artista aparece na tela, como as licenças Creative Commons pedem.
